---

## 🌟 Key Features

* **⚡ Ultra-Fast Minimalist UI:** Built with clean HTML5, CSS3, and modern JavaScript without heavy framework bloat.
* **🤖 Interactive AI Resume Assistant:** An embedded conversational assistant that answers recruiter queries about skills, projects, and qualifications in real time.
* **📬 Direct Email Contact Delivery:** Powered by Web3Forms for instant recruiter message delivery directly to `thotaushasree09@gmail.com`.
* **🎓 Academic & Career Journey:** Clean timeline displaying B.Tech in CSE at KL University (8.7 CGPA), relevant coursework, and software development training.
* **📁 Featured Projects:** Highlights production platforms including **Campus Placement & Recruitment Drive Portal**, **Savory AI Bistro**, and **Food Delivery Big Data Analytics**.
* **📄 Integrated Resume Viewer:** One-click instant viewing and download of the official resume PDF.

---

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3 (Modern Flexbox & CSS Grid), JavaScript (ES6+), Lucide Icons
* **Hosting & CI/CD:** Vercel / GitHub Pages
* **Contact Integration:** Web3Forms API & Mailto Fallback
* **Local Backend (Optional):** Python, FastAPI, SQLite, SQLAlchemy, Uvicorn

---

## 💻 Local Development

1. Open `index.html` directly in any browser.
2. (Optional) Run the FastAPI backend:
   ```bash
   run_backend.bat
   ```
   or:
   ```bash
   cd backend
   python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
   ```
